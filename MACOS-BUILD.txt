Set ZIG, SDKROOT, LINTHESIA_FRAMEWORKS to absolute paths, then run:
bash build-macos-local.sh

Use a writable, locally extracted SDK because the script creates a LocalFrameworks symlink.
The frameworks can be obtained from ../Linthesia.app/Contents/Frameworks.
This compiles build-macos/linthesia. To update the app, copy it into
../Linthesia.app/Contents/MacOS/linthesia and run:
codesign --force --deep --sign - ../Linthesia.app
Keep the bundled Contents/Resources and Contents/Frameworks directories.
